# Student Performance Visualization

This project focuses on analyzing and visualizing student performance using Python. The dataset contains information about students' gender, race/ethnicity, parental education, lunch type, test preparation, and scores in mathematics, reading, and writing.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn

## Visualizations

The project includes different types of charts:

* Scatter Plot
* Histogram
* Bar Chart
* Box Plot
* Pie Chart

## Dataset

The project uses the **Students Performance in Exams** dataset from Kaggle.

## Purpose

The main purpose of this project is to practice data handling and visualization using Python libraries and understand patterns and relationships within student performance data.
